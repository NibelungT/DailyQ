# SPEC.md — 交互规格

> 规则编号是全项目的锚点：代码注释、测试名、缺陷单都引用它。
> 每条规则都写成"可验收"的形式——看到编号就该能写出断言。
> 视觉细节以 `参考/原型.html` 为准，本文件只定行为。

## 0. 术语

| 术语 | 含义 |
|---|---|
| 事件 Event | 一个长期跟踪的事项，自带类型、目标、周期、颜色 |
| 记录 Log | 一次打卡行为，带 `occurredAt`、数值、可选备注 |
| 周期 Period | 由 `resetCycle` 决定的统计窗口（无/每天/每周/每月） |
| 当前值 current | 事件在"当前周期"内的记录数值之和 |
| 归属日 dayKey | `occurredAt` 所在自然日（设备本地时区） |

**三种计量类型**（决定记录面板控件、目标单位、卡片展示）：

| metricType | 语义 | 首页圆圈 | 单位 | 记录控件 |
|---|---|---|---|---|
| `count` | 做了几次 | 周期内累计次数 | 次 | 步进器 `− N +` |
| `duration` | 累计多久 | 周期内累计分钟 | 分钟 | 步进器 + 正计时 |
| `value` | 累计多少 | 周期内累计数值 | 毫升/页/公里… | 数字键盘 + 快捷加量 |

## 1. 信息架构

```
首页（事件列表）
├─ 筛选：所有 / 今日 / 已归档 / + 新增
├─ 记录面板（底部弹层）
├─ 长按卡片 → 编辑 / 归档 / 置顶 / 删除
└─ 新建事件（全屏页，右上确认保存）
统计（全屏页）
├─ 粒度：日 / 周 / 月 / 年
├─ 周期导航（左右箭头）
└─ 排序 / 分组筛选 / 清空记录
```

导航约定：
- 记录面板用**底部弹层**，下滑或点遮罩关闭，不拦截未保存（备注视为草稿）。
- 新建/编辑用**全屏页**，关闭时必须拦截未保存修改。
- 统计用**全屏页**，关闭不拦截。

## 2. 共用组件

| 组件 | 规格 |
|---|---|
| 筛选胶囊 `FilterChip` | 高 40，圆角 999；选中=浅色底+深色字，未选中=深灰底+浅灰字 |
| 事件卡片 `EventCard` | 圆角 24，内边距 16/18；左：图标+名称+副标题+进度条；右：直径 62 的计数圆圈 |
| 计数圆圈 `CountCircle` | 背景=事件主题色；文字色按亮度自动取深/浅；达成后右上叠加对勾（受 `showCheck` 控制） |
| 分段控件 `Segmented` | 4px 内边距的深色槽，选中项为更亮的圆角块；禁用时整体 45% 透明 |
| 开关 `Switch` | 开=主题青绿；关=灰色；禁用不置灰（v1 无禁用态） |
| 步进器 `Stepper` | 左右圆形按钮 46×46，中间数字 38pt，下方单位 12pt |
| 底部按钮 `PrimaryButton` | 通栏，圆角 16，背景取事件主题色 |

数字格式：卡片圆圈 ≥1000 时显示 `2k`/`12k`；副标题与统计值显示完整数字（`2,000`）。

## 3. P0 首页 · 事件列表

### 3.1 布局
顶部品牌标题 → 筛选胶囊行（可横向滚动）→ 卡片列表（可纵向滚动）→ 底部三段导航（统计 / 圆形加号 / 更多）。

卡片副标题由三段组成，用 `·` 分隔：`类型 · 重置：周期 · 当前/目标`。当 `resetCycle = none` 时省略中间段；当 `target` 为空时第三段只显示 `当前 + 单位`。

### 3.2 规则

| 编号 | 触发 / 条件 | 必须的行为 |
|---|---|---|
| HOME-R-01 | 点击筛选胶囊 | 切换列表数据源，列表淡入；不重新加载整页、不重置滚动位置以外的状态 |
| HOME-R-02 | 点计数圆圈，且 `quickLog = true` | 立即写入 1 条记录（`value = step`），当前值 +step，进度条动画，圆圈数字滚动并回弹，轻震；弹出 3 秒撤销条 |
| HOME-R-03 | 点计数圆圈，且 `quickLog = false` | 打开记录面板，预填当前时刻与 `step` |
| HOME-R-04 | 点卡片空白区域 | 打开记录面板（同 HOME-R-03） |
| HOME-R-05 | 长按卡片 520ms | 弹出操作菜单：编辑 / 归档（或恢复）/ 置顶 / 删除 |
| HOME-R-06 | 点「+ 新增」胶囊或底部圆形加号 | 进入新建事件页 |
| HOME-R-07 | 点底部左侧图标 | 进入统计页 |
| HOME-R-08 | 下拉列表 | 刷新（v1 无网络，仅触发一次重算与骨架闪动） |
| HOME-R-09 | 同一天内重复点圆圈 | 继续累加，但每次写入前都要过 `SYS-R-09` 的上限校验 |

筛选语义：`今日` = `resetCycle` 为 `daily` 或 `none` 且未归档的事件；`已归档` = `archived = true`；`所有` = 未归档的全部。

### 3.3 状态

| 状态 | 表现 |
|---|---|
| 首次空 | 插画 + 「还没有要记录的事」+ 主按钮「创建第一个事件」 |
| 加载 | 三张卡片骨架屏，尺寸与真实卡片一致 |
| 局部空（今日） | 「今日没有需要打卡的事件」+「查看全部」 |
| 空（已归档） | 「还没有归档的事件」，无主按钮 |
| 错误 | 「数据加载失败」+ 重试，保留上次缓存内容 |
| 极限 | 列表虚拟滚动；超过 200 条启用分组折叠 |

## 4. P0 记录面板

### 4.1 结构
拖拽条 → 头部（关闭 / 事件图标+名称 / 确认）→ 记录时间（日历图标 + 日期胶囊 + 时间胶囊）→ 数量区（按类型渲染）→ 备注（多行，占位「选填」，上限 500 字）→ 附件按钮（+，v1 只提示「暂未开放」）→ 底部主按钮。

### 4.2 规则

| 编号 | 触发 / 条件 | 必须的行为 |
|---|---|---|
| LOG-R-01 | 点日期胶囊 | 唤起日期选择器；可选范围 = 事件 `startDate` 至今天；未来日期置灰 |
| LOG-R-02 | 点时间胶囊 | 唤起时间选择器，精确到分钟 |
| LOG-R-03 | 日期被改到非今天 | 顶部出现提示条「该记录将计入 M 月 D 日」；提交后按该日归属统计，且**不改动**该事件其它记录 |
| LOG-R-04 | 点附件按钮 | v1 提示「暂未开放」，不写数据 |
| LOG-R-05 | 点关闭 / 下滑 / 点遮罩，且备注或附件非空 | 二次确认「放弃本次记录？」；备注为空则直接关闭 |
| LOG-R-06 | 点确认 | 校验数值 > 0（`count` 允许 ≥1），写入记录，关闭面板，首页即时更新 |
| LOG-R-07 | 提交时该归属日已达 `dailyLimit` | 阻止提交，提示「今日记录已达上限（N 次）」 |
| LOG-R-08 | 提交时间晚于当前时间 +1 分钟 | 阻止提交，提示「不能记录未来的时间」 |
| LOG-R-09 | `metricType = duration` 点「开始计时」 | 计时器开始走；点「停止并计入」把 `max(1, round(秒/60))` 加到步进器数值上 |

提交成功后统一：关闭面板 → 首页刷新 → 轻震 → 3 秒撤销条。

### 4.3 边界
- 补记窗口：允许过去 30 天；更早则提示「最多补记 30 天」。
- 上限按**归属日**计数，不按提交时刻。
- 同一条记录重复提交必须幂等（见 `SYS-R-06`）。

## 5. P0 新建 / 编辑事件

### 5.1 分组（顺序固定）
身份（图标 / 名称 / 说明 / 主题色 / 分组）→ 类型 → 计量（目标 / 每次记录 / 重置周期）→ 提醒（定期 / 跟进）→ 高级（快速记录 / 日上限 / 显示对号）。
底部固定条：开始时间、结束时间（两枚胶囊）。

### 5.2 规则

| 编号 | 触发 / 条件 | 必须的行为 |
|---|---|---|
| CREATE-R-01 | 切换类型 | 联动单位与默认步长：`count`→次/1，`duration`→分钟/5，`value`→毫升/250；已填目标保留但提示单位变化。**单位回到该类型的默认值，用户自定义过的单位不跨类型保留** |
| CREATE-R-02 | 编辑已有事件 | 类型分段控件禁用（45% 透明 + 点击提示「类型创建后不可修改」），store 层再次拒绝修改 |
| CREATE-R-03 | 名称为空点保存 | 不保存，输入框抖动 + 提示「请填写事件名称」 |
| CREATE-R-04 | 目标 ≤ 0 | 不保存，提示「目标需大于 0」 |
| CREATE-R-05 | 结束时间早于开始时间 | 结束时间清空，提示「结束时间不能早于开始时间」 |
| CREATE-R-06 | 有改动时点关闭 | 二次确认「放弃本次编辑？」 |
| CREATE-R-07 | 保存成功 | 新事件插入列表首位；编辑则原位更新；toast 提示 |
| CREATE-R-08 | 点目标 / 每次记录后面的单位胶囊 | 打开单位面板：上方输入框可直接填（≤6 字），下方为该类型预设，点预设填入输入框，点确定生效；单位只影响展示文案，不换算数值 |
| CREATE-R-09 | 单位留空点确定 | 回退到该类型的默认单位（次 / 分钟 / 毫升） |

字段约束见 `docs/DATA.md` 的校验表。

### 5.3 状态
仅两态：正常、校验错误（行内红字 + 输入框描边）。没有加载态（本地写入是同步的）。

## 6. P1 统计

### 6.1 结构
头部（关闭 / 统计 / 排序 / 筛选 / 清空）→ 汇总卡（总次数、总天数）→ 粒度分段 → 周期导航（‹ 区间 ›）→ 事件行（图标+名称、`X当前周期累计`、点阵）。

### 6.2 规则

| 编号 | 触发 / 条件 | 必须的行为 |
|---|---|---|
| STAT-R-01 | 切换粒度或翻页 | 汇总卡数值**不变**：总次数=全部记录数，总天数=去重后归属日数 |
| STAT-R-02 | 切换粒度 | 点阵格数随之变化：日=24、周=7、月=当月天数、年=12；周视图在点下方显示「一二三四五六日」 |
| STAT-R-03 | 渲染圆点 | 未记录=空心灰；有记录按 `min(1, 值/目标)` 计算不透明度（0.35→1.0）；无目标时只要有记录即实色 |
| STAT-R-04 | 点左箭头 | 回看上一個周期；早于事件开始日仍可看，但全为空 |
| STAT-R-05 | 点右箭头且已在当前周期 | 阻止，提示「不能查看未来」 |
| STAT-R-06 | 排序 | 三选一：默认顺序 / 名称 / 本周期累计（降序） |
| STAT-R-07 | 分组筛选 | 按 `groupId` 过滤事件行；「全部」恢复 |
| STAT-R-08 | 点清空 | 二次确认，文案必须包含将删除的记录条数；确认后清空全部记录但保留事件 |
| STAT-R-09 | 点事件行 | 进入单事件详情（v1 可先不做，点击无响应即可，但不要报错） |

## 7. 全局规则（跨页面，最容易漏）

| 编号 | 规则 | 说明 |
|---|---|---|
| SYS-R-01 | 归属日 | 记录归属于 `occurredAt` 所在自然日，设备本地时区；跨零点、跨时区都不重算历史 |
| SYS-R-02 | 周期起点 | `daily`=今天 00:00；`weekly`=本周一 00:00（周起始日可配置，默认周一）；`monthly`=本月 1 日 00:00；`none`=不重置（累计全部） |
| SYS-R-03 | 惰性清零 | 当前值 = 周期起点之后所有记录求和；不存在"清零动作" |
| SYS-R-04 | 三种达成态 | 未达成（`<目标`）/ 达成（`=目标`）/ 超额（`>目标`）；进度条封顶 100%，超额不换色只加描边 |
| SYS-R-05 | 可撤销 | 删除一律软删除 + 3 秒撤销；撤销后完全回滚，不留痕迹 |
| SYS-R-06 | 幂等 | 记录写入以 `id` 去重；重复提交不产生第二条 |
| SYS-R-07 | 归档 | 归档后首页默认不显示、统计不显示；已归档页可恢复 |
| SYS-R-08 | 排序 | 置顶把事件移到列表首位；其余按创建时间倒序 |
| SYS-R-09 | 日上限 | `dailyLimit > 0` 时，同一归属日的记录条数达到上限即拦截，快速记录与面板提交都要拦 |
| SYS-R-10 | 未开始 | `startDate` 在今天之后的事件不出现在「今日」，但仍出现在「所有」 |

## 8. 关键文案（不要自由发挥）

| 场景 | 文案 |
|---|---|
| 记录成功（未达成） | `已记录 · {当前}/{目标}` |
| 记录成功（达成） | `已完成 · {事件名}` |
| 补记成功 | `已补记到 {M/D}` |
| 超上限 | `今日记录已达上限（{N} 次）` |
| 未来时间 | `不能记录未来的时间` |
| 类型锁定 | `类型创建后不可修改` |
| 空态（首页） | `还没有要记录的事` / `创建第一个事件` |
| 空态（统计） | `还没有记录，去首页开始第一次打卡` |
| 清空确认 | `将删除全部 {N} 条记录，事件本身保留。此操作不可恢复。` |

## 9. v1 不做

分组管理页 / 通知真实推送 / 图片附件 / 云同步 / 浅色主题。

这些入口可以留位置，但点击不能报错——要么提示"暂未开放"，要么不响应。

## 10. 事件详情（DETAIL）

入口：首页长按卡片 → 查看详情；统计页点事件行。

| 编号 | 规则 |
|---|---|
| DETAIL-R-01 | 连续天数：今天已达成则从今天开始往后数；今天未达成则从昨天开始数，不算断 |
| DETAIL-R-02 | 日历格子：有记录按 `min(1, 值/目标)` 着色（0.28→1.0 不透明度），无记录为深灰；今天加描边；未来日期与事件开始日之前置灰且不可点 |
| DETAIL-R-03 | 日历可翻到上一个月，不能翻到未来月份；周起始日跟随设置 |
| DETAIL-R-04 | 记录流水按时间倒序，最多显示 30 条，超出提示"仅显示最近 30 条" |
| DETAIL-R-05 | 删除单条记录是软删除，3 秒内可撤销（SYS-R-05），撤销后连续天数与统计同步恢复 |
| DETAIL-R-06 | 底部「归档」二次确认可逆；归档后返回首页，该事件从列表消失 |
| DETAIL-R-07 | 底部「记录一次」直接打开记录面板，不需要回首页 |

## 11. 设置（SET）

入口：首页底部右侧图标。

| 编号 | 规则 |
|---|---|
| SET-R-01 | 周起始日（周一/周日）影响：统计周视图的区间起点、每周重置的周期窗口、详情页日历的列顺序 |
| SET-R-02 | 每日提醒：应用内提醒条，开关 + 时间；当天点关闭后当天不再出现；**不做系统推送**（v1.1 边界） |
| SET-R-03 | 提醒条只在「今天还有未达成事件」且开关打开时出现，文案为"还有 N 件事没完成，别断了" |
| SET-R-04 | 导出 CSV：列固定为 `日期,时间,事件,类型,数值,单位,备注`，含逗号/引号的字段需转义；导出 JSON 为完整快照 |
| SET-R-05 | 清空记录保留事件；重置演示数据丢弃当前数据并恢复 4 个种子事件，两者都要二次确认 |
| SET-R-06 | 导出走剪贴板，提示里给出复制行数，便于确认不是空文件 |
